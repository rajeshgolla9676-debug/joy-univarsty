This is a student project template, not an official university service. Before production use, configure this notice for the actual operator and applicable privacy requirements.

Information and storage

The portal may process name, student ID, email, department, course, academic year, and optional phone number. Supabase Auth manages passwords and sessions; passwords are not stored in the profile table.

Before using real data

Review access controls, retention, backups, institutional approval, and support contact details before entering real student information.
